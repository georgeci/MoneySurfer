## TL;DR for agents

- Keep documentation concise and linkable.
- Use relative links that survive repository moves.
- Do not create huge comment-style docs inside code.
- Read this before editing markdown style.

READ WHEN:
- editing markdown
- adding links
- adding headings
- adding code references

<!-- AI:SECTION id=markdown-rules task=docs,markdown,links -->
## Rules

- Use one `#` title per file.
- Use sentence-case headings unless a local convention requires otherwise.
- Prefer links to docs over long code comments.
- Use indexed Compose placeholders in docs examples: `%1$s`, `%1$d`, `%2$s`.
- Keep generated TOC inside `
`.
