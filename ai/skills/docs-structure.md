## Rules

- Prefer short files over a single large document.
- Use summaries for large topics: `topic.AI_SUMMARY.md` beside `topic.md`.
- Each stable doc starts with `## TL;DR for agents`.
- Each stable doc includes a `READ WHEN:` block near the top.
- Use ADR files for decisions with `Decision`, `Why`, `Rules`, and `Consequences`.
- Use managed TOC blocks generated by `scripts/docs_tool.py toc`.
- Add or update `AI:SECTION` markers when introducing addressable content.
- Run `python3 scripts/docs_tool.py all` after changes.
